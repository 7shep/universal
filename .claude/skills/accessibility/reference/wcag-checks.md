# Accessibility check-to-criterion map

Every check `/accessibility` performs, how it is actually computed (never simulated), the WCAG 2.2
success criterion it maps to, and its default classification per
[`audit/reference/finding-schema.md`](../../audit/reference/finding-schema.md)'s
`deterministic`/`judgment` vocabulary. Load this file whenever the skill needs the exact citation
or method for a check — the main `SKILL.md` workflow references it by section.

None of these checks run an automated tool (no axe-core, Lighthouse, WAVE, or Pa11y integration
exists in this repository as of this writing). Every "deterministic" check below is deterministic
because the underlying fact is mechanically computable by direct inspection of source and resolved
styles — not because a scanner produced it. Say so explicitly in every report; never imply a
scanner ran.

## Semantics

| Check                                                                                                                  | Method                                                                                    | WCAG 2.2 SC                                     | Default classification                                                             |
| ---------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------- | ---------------------------------------------------------------------------------- |
| Interactive control uses a non-semantic element (`<div>`/`<span>` as button/link) without `role` and keyboard handling | Read the JSX/HTML: element type, presence of `role`, `tabIndex`, `onKeyDown`/`onKeyPress` | 4.1.2 Name, Role, Value (A); 2.1.1 Keyboard (A) | Deterministic — element type and attribute presence are directly observable        |
| Heading levels skip a level (e.g. `h2` -> `h4`) or page has no `h1`                                                    | Extract heading order from the rendered/JSX tree                                          | 1.3.1 Info and Relationships (A)                | Deterministic for the skip/absence fact; whether it's _confusing_ is judgment      |
| Landmark regions (`header`/`nav`/`main`/`footer`) missing or duplicated without labels                                 | Read top-level layout markup                                                              | 1.3.1 Info and Relationships (A)                | Deterministic for presence/absence; adequacy of the landmark structure is judgment |
| List/table semantics used for pure layout, or real list/table content not marked up as one                             | Read markup structure against visual/content intent                                       | 1.3.1 Info and Relationships (A)                | Judgment — requires interpreting intent, not just markup shape                     |

## Keyboard interaction

| Check                                                                                                           | Method                                                                                                | WCAG 2.2 SC                | Default classification                                                                             |
| --------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | -------------------------- | -------------------------------------------------------------------------------------------------- |
| Custom control has no keyboard event handler equivalent to its pointer handler                                  | Read the component: compare `onClick`/pointer handlers against `onKeyDown`/`onKeyUp`/native semantics | 2.1.1 Keyboard (A)         | Deterministic — handler presence/absence is directly observable in source                          |
| `tabIndex` value greater than `0` (reorders natural tab order) or a positive value on a non-interactive element | Grep/read for `tabIndex`/`tabindex` values                                                            | 2.4.3 Focus Order (A)      | Deterministic for the literal value; whether the resulting order is confusing is judgment          |
| A widget appears to trap focus (a modal/menu with no visible or coded escape path in source)                    | Read open/close and focus-management logic                                                            | 2.1.2 No Keyboard Trap (A) | Judgment unless source shows an unconditional focus-forcing loop with no exit — then deterministic |
| Click-only affordance with no native control or keyboard path at all                                            | Read the element and its handlers                                                                     | 2.1.1 Keyboard (A)         | Deterministic                                                                                      |

## Focus behavior

| Check                                                                                                                                                                                  | Method                                                                                                 | WCAG 2.2 SC                                                        | Default classification                                                                   |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| Focus indicator explicitly suppressed with no replacement (`outline: none`/`outline: 0` on `:focus`/`:focus-visible` and no alternative treatment in the same rule or a cascading one) | Read the CSS rule and confirm no replacement (box-shadow, border change, background change) is present | 2.4.7 Focus Visible (AA); 2.4.11 Focus Not Obscured (Minimum) (AA) | Deterministic — confirmed in source, not inferred from the mere absence of a custom rule |
| Focus indicator present but obscured by an overlapping fixed/sticky element at a checked viewport                                                                                      | Requires a captured/inspected rendered viewport showing the overlap                                    | 2.4.11 Focus Not Obscured (Minimum) (AA)                           | Deterministic only with real rendered evidence; otherwise not claimed                    |
| Focus order does not follow reading/visual order                                                                                                                                       | Requires rendered inspection or careful DOM-order-vs-layout reasoning                                  | 2.4.3 Focus Order (A)                                              | Judgment unless source order and CSS positioning make the mismatch unambiguous           |

## Labels (accessible names)

| Check                                                                                                                     | Method                                                                            | WCAG 2.2 SC                                                                                     | Default classification                                                   |
| ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Form input (`input`/`select`/`textarea`) has no associated `<label>`, `aria-label`, or `aria-labelledby`                  | Read the form markup and match `id`/`htmlFor` pairs and ARIA labelling attributes | 3.3.2 Labels or Instructions (A); 4.1.2 Name, Role, Value (A); 1.3.1 Info and Relationships (A) | Deterministic                                                            |
| Icon-only interactive control (button/link with no visible text) has no `aria-label`/`aria-labelledby`/`title`+equivalent | Read the control's children and attributes                                        | 4.1.2 Name, Role, Value (A); 2.4.4 Link Purpose (In Context) (A) for links                      | Deterministic                                                            |
| `<img>` with no `alt` attribute, or a decorative image with a non-empty `alt` that duplicates adjacent text               | Read the element and surrounding content                                          | 1.1.1 Non-text Content (A)                                                                      | Deterministic for presence/absence of `alt`; wording quality is judgment |
| Accessible name present but unclear or not descriptive of the control's purpose                                           | Requires reading the label text against the control's function                    | 2.4.6 Headings and Labels (AA)                                                                  | Judgment                                                                 |

## Contrast

| Check                                                                                                                                                          | Method                                                                                                                | WCAG 2.2 SC                   | Default classification                                                                                     |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ----------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Text foreground/background contrast ratio below the required threshold (4.5:1 normal text, 3:1 large text — 18pt/24px regular or 14pt/18.66px bold and larger) | Resolve the literal foreground and background color values from source/tokens/computed styles, then compute the ratio | 1.4.3 Contrast (Minimum) (AA) | Deterministic — the ratio is a computation, not an opinion, once both colors are confirmed resolved values |
| Non-text UI component or graphical object (control borders, icons conveying meaning, focus indicators) below 3:1 against adjacent color(s)                     | Same resolved-color computation applied to the non-text element                                                       | 1.4.11 Non-text Contrast (AA) | Deterministic when both colors are confirmed resolved values                                               |
| Contrast cannot be computed because a color is theme-, variable-, or runtime-derived and not resolvable from static inspection                                 | N/A — flag as a gap, do not guess                                                                                     | 1.4.3 / 1.4.11                | Not reported as a finding — recorded as an evidence gap instead                                            |

## Touch targets

| Check                                                                                                                                                                                                | Method                                                              | WCAG 2.2 SC                      | Default classification                                                              |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | -------------------------------- | ----------------------------------------------------------------------------------- |
| Interactive control's computed hit area is smaller than 24x24 CSS px, with no exception (inline text link, essential/legally required size, or an equivalent larger target available adjacent to it) | Resolve width/height/padding from CSS/tokens applied to the control | 2.5.8 Target Size (Minimum) (AA) | Deterministic when dimensions are resolvable from static styles                     |
| Two adjacent small targets have insufficient spacing to avoid accidental activation                                                                                                                  | Resolve gap/margin between adjacent controls                        | 2.5.8 Target Size (Minimum) (AA) | Deterministic when spacing is resolvable; judgment if it depends on dynamic content |

## Reduced motion

| Check                                                                                                                                                                                               | Method                                                                          | WCAG 2.2 SC                                                                                           | Default classification                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| CSS/JS drives a non-essential animation, transition, parallax, or auto-playing motion effect with no `prefers-reduced-motion` media query or equivalent guard anywhere in the cascade for that rule | Read the CSS/animation source and confirm no reduced-motion guard exists for it | 2.3.3 Animation from Interactions (AAA); 2.2.2 Pause, Stop, Hide (A) for auto-updating/moving content | Deterministic for the presence/absence fact when the motion is clearly decorative (loops, parallax, spin); judgment when essentiality is ambiguous |
| Motion is essential to conveying the interaction result (e.g. a drag-and-drop reorder) and has no reduced-motion-safe fallback                                                                      | Requires judging whether the motion is essential to the interaction's meaning   | 2.3.3 Animation from Interactions (AAA)                                                               | Judgment                                                                                                                                           |

## Notes on WCAG 2.2 vs. 2.1

WCAG 2.2 added 2.4.11 Focus Not Obscured (Minimum), 2.5.8 Target Size (Minimum), and others not
present in 2.1. Cite the 2.2 numbering above; if a project's stated compliance target is 2.1, say so
in the report and note that 2.4.11/2.5.8 findings are 2.2-only.
